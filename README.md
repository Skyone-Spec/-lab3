# 四星背后｜MovieLens 交互数据故事

这是课程“交互式可视化”作业，研究问题是：**一个平均分隐藏了多少关于样本与分歧的信息？**作品分为“榜单的幻觉”“高分的证据量”“均分隐藏的分歧”三幕，可用顶部章节导航直接进入。

## 打开与探索

直接访问部署站点，或在本地通过静态 HTTP 服务打开 `index.html`。页面会从 `data/movies.csv` 与 `data/ratings.csv` 自动读取 MovieLens Small 数据。可按类型、发行年代和最低评分人数筛选；切换榜单指标；点击散点或榜单行联动查看单片评分详情与评分分布。

在线体验：<https://skyone-spec.github.io/-lab3/>。

- 点击敏感性曲线的门槛节点，同步筛选散点、统计和榜单。
- 调整平滑权重 m（0–100），比较小样本处理对排名的影响。
- 拖动权重会自动切换散点与榜单到平滑评分；可切回原始均分对照。详情并列显示两种分数，原始评分分布保持原样。
- 上方折线记录入榜电影的重合数，名单不变时线可能不动；实时改变量和影片例子可用于确认分数变化。
- 开启散点框选，拖动矩形后只对局部电影计算统计和榜单；返回点选可查看电影详情。
- 清除框选或恢复默认即可返回；门槛节点和榜单支持键盘 Enter/空格。
- 单片详情可“固定为对照”，再点选另一部电影，比较各星级占比或评分条数；默认展示均分接近但分歧不同的两部真实影片。
- 开场信息由实际加载数据计算；默认案例自动搜索各至少 50 条评分、均分差不超过 0.01、标准差差值最大的影片对。
- 全局筛选默认折叠，包含 1930 年以前和未知年份；同一圆点遮盖多部影片时，可用“同位置影片”列表切换。
- 图表库和 ZIP 解析库已随 `assets/` 发布，本地静态预览不再依赖 CDN。

复现报告汇总：安装 `pandas` 和 `scipy` 后运行 `python analysis/research.py`。网页运行无需 Python。

## 文件

- `index.html`：D3.js 交互式可视化
- `data/`：MovieLens Small 官方数据 CSV 与许可说明
- `研究报告.md`：研究问题、设计理由、数据发现、局限与开发过程
- `analysis/research.py`：复现候选量、重合度与 Spearman 相关
- `assets/`：D3 7.9.0、JSZip 3.10.1 及许可

## GitHub Pages 部署

将本目录文件推送到 GitHub 仓库默认分支，然后在仓库 **Settings → Pages** 选择从分支部署，分支选 `main`，目录选 `/ (root)`。该项目无需构建步骤或服务器端程序。启用后等待 GitHub Pages 完成发布，并将公开网址填入报告。

## 数据与引用

数据来自 [GroupLens MovieLens Latest Small](https://grouplens.org/datasets/movielens/latest/)，本目录保留官方 README / 使用许可。外部图表库为 [D3.js](https://d3js.org/)；ZIP 本地导入使用 [JSZip](https://stuk.github.io/jszip/)。
